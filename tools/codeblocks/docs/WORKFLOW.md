# 日々の作業手順

管理ツール `codeblocks.html` をブラウザ（Edge / Chrome）で開くだけで動きます。
ネットワーク・インストール・Node・Python は不要です。

```
① 読み込む → ② 選ぶ → ③ AIに依頼 → ④ 返答を取り込む → ⑤ 保存
```

画面上部の進捗バーがこの順に進みます。各画面の「？」で説明が開きます。

---

## ① 読み込む

1. 本体 HTML を画面中央にドロップ（または「ファイルを選ぶ」）。
2. 「○○行 / ○○ブロックに分けました」「復元チェック: OK」を確認する。
   - 復元チェック = 分けたブロックをつなぎ直すと元のファイルと 1 文字違わず一致すること。
   - 「一部を粗く分けました」と出た場合も差し替えは可能（一覧が粗くなるだけ）。
3. 前回の作業がブラウザに残っていれば「前回の続きを開く」から再開できる。

## ② 選ぶ

1. 検索ボックスに関数名やコメントの一部を入れて絞り込む。
2. 直したい関数にチェックを入れる。右側にコードと「呼んでいる / 呼ばれている」が出る。
3. 右上の「AI に渡す範囲」で文字数を確認する。
   - 通常は「関連の署名だけ」で十分。関連関数も直す必要がありそうなら「関連も本文ごと含める」。
   - 「関連もまとめて選ぶ」で呼ぶ / 呼ばれる関数を一度に選択できる。
4. 「次へ: ③ AI に依頼する」。

## ③ AI に依頼

1. 「やりたいこと」を書く（例: 「集計が 0 件のとき例外になるのを直したい」）。
2. 依頼の種類を選ぶ（バグ修正 / 機能追加 / 整理 / 新しい部品 / 説明）。
3. 「プロンプトをコピー」→ 社内 AI に貼り付けて送信。
4. AI の返答を**そのまま全部**コピーする。

## ④ 返答を取り込む

1. 貼り付け欄に返答を貼る。自動で解析され、ブロックごとのカードが出る。
   - 緑「置換」 / 青「追加」 / 赤「削除」 / 黄「⚠ 警告」
2. 「差分を見る」で変更行を確認する。
3. ⚠ 省略サインが出たら、「省略せず全文で再依頼するプロンプトをコピー」→ AI に再依頼 → 貼り直す。
4. 取り込むカードにチェックを入れ、「チェックした変更を適用」。
5. 「構文チェック OK」を確認。エラーなら「適用を取り消す」で戻せる（直前 1 回分）。

## ⑤ 保存

1. 「新しい HTML をダウンロード」。ファイル名は `元の名前.YYYYMMDD-HHMM.html`。
2. ダウンロードしたファイルをブラウザで開いて動作確認する。
3. 問題なければ元のファイルと差し替える（古いものは日付付きで残しておく）。
4. 続けて修正するなら「続けて別の修正をする → ②へ」。

## 部品の再利用（⑤ の「部品の再利用・書き出し」）

- **部品抽出**: 選んだブロック + それが呼ぶ関数を 1 つの `.js` にまとめてダウンロード。
  他のツールに `<script src="部品.js">` または貼り付けで再利用できる。
- **カタログ (Markdown)**: 全ブロックの名前・署名・役割コメント・依存の一覧。
  「このツールに何があるか」を AI や人に渡す索引になる。
- **ブロック zip**: 1 ブロック 1 ファイルで書き出し。差分比較や検索に使う。

## 管理ツール自体を改修するとき

`codeblocks.html` を `codeblocks.html` 自身に読み込ませ、同じ手順で依頼・取り込み・保存する。
ツール本体は規約どおり「1 つの `<script>` にトップレベル関数が並ぶ」構造なので、そのまま扱える。

## よくある失敗

| 症状 | 原因 | 対処 |
|---|---|---|
| 取り込み結果が「不明」ばかり | AI が封筒形式もコードフェンスも付けていない | 返答形式を守るよう再依頼。または該当関数だけ ``` で囲んで貼り直す |
| 「名前の不一致」警告 | AI が関数名を変えた | 意図した改名なら、旧名を DELETE、新名を NEW BLOCK として扱う（カードの「追加として扱う」） |
| 構文エラー | ブロックの途中で切れている | 該当ブロックだけ再依頼 |
| ダウンロード後に動かない | 呼び出し元との不整合 | ② で「呼ばれている」関数も選んで再依頼 |
