# プロンプト雛形集

管理ツール `codeblocks.html` に内蔵されているテンプレートの原本です。
ツールの「設定 → テンプレート」で編集でき、初期化するとこの内容に戻ります。

プレースホルダ:

| 記号 | 置換内容 |
|---|---|
| `{{TASK}}` | ③ で入力した「やりたいこと」 |
| `{{RULES}}` | CONVENTIONS.md の「AI 向け要約」 |
| `{{FORMAT}}` | RESPONSE_FORMAT.md の要約（返答形式の指示） |
| `{{BLOCKS}}` | 選択したブロックの全文（`=== BLOCK: 名前 ===` 付き） |
| `{{RELATED}}` | 選択ブロックが呼ぶ / 呼ばれる関数の署名一覧（本文なし） |
| `{{TOC}}` | ファイル全体の目次（名前・種別・行数） |
| `{{FULL}}` | ファイル全文（全文モードのみ） |
| `{{FILE}}` | ファイル名 |

---

## 共通ヘッダ（すべてのテンプレートの先頭に付く）

```
あなたは単一 HTML ファイルで作られた業務ツールの改修を手伝う開発者です。
ファイル名: {{FILE}}
このファイルは「ブロック（トップレベル宣言）」単位で管理されています。
以下の規約と返答形式を必ず守ってください。

{{RULES}}

{{FORMAT}}
```

## テンプレート: バグ修正

```
【依頼】バグ修正
{{TASK}}

【手順】
1. まず原因を 3 行以内で説明する。
2. 修正が必要なブロックだけを BLOCK 形式で全文返す。
3. 動作確認の手順を 3 行以内で書く。

【対象ブロック】
{{BLOCKS}}

【関連する関数の署名（参考。変更が必要なら BLOCK で返すこと）】
{{RELATED}}

【ファイル全体の目次】
{{TOC}}
```

## テンプレート: 機能追加

```
【依頼】機能追加
{{TASK}}

【手順】
1. 変更方針を 5 行以内で説明する（どのブロックを変え、どの関数を新設するか）。
2. 変更するブロックは BLOCK 形式で全文、新設する関数は NEW BLOCK 形式で返す。
3. 既存の関数で再利用できるものは再利用し、同じ役割の関数を新設しない。

【対象ブロック】
{{BLOCKS}}

【関連する関数の署名】
{{RELATED}}

【ファイル全体の目次（再利用できる関数を探すこと）】
{{TOC}}
```

## テンプレート: 整理・リファクタ

```
【依頼】整理・リファクタ（動作を変えない）
{{TASK}}

【条件】
- 外から見た動作・関数名・引数・戻り値は変えない。変える必要がある場合は理由を先に書き、呼び出し元も返す。
- 長い関数は 30〜150 行の関数に分割し、分割後の関数は NEW BLOCK で返す。
- 削除してよい関数があれば DELETE BLOCK で示す。

【対象ブロック】
{{BLOCKS}}

【関連する関数の署名】
{{RELATED}}

【ファイル全体の目次】
{{TOC}}
```

## テンプレート: 新しい部品を作る

```
【依頼】新しい部品（関数群）の新設
{{TASK}}

【条件】
- 既存コードに依存しない、引数と戻り値だけで完結する関数として作る（他ツールでも再利用するため）。
- 各関数の直前に 1 行コメントで役割を書く。
- すべて NEW BLOCK 形式で返す。after には {{ANCHOR}} を指定する。

【ファイル全体の目次（同じ役割の関数が既にないか確認すること）】
{{TOC}}

【参考: 関連する既存関数の署名】
{{RELATED}}
```

## テンプレート: 説明してほしい

```
【依頼】コードの説明
{{TASK}}

以下のブロックについて、役割・入力・出力・副作用・呼び出し関係を日本語で説明してください。
コードは返さないでください。

【対象ブロック】
{{BLOCKS}}

【関連する関数の署名】
{{RELATED}}
```

## テンプレート: 全文で依頼（従来方式）

```
【依頼】
{{TASK}}

【条件】
- 以下にファイル全文を示す。変更が必要なブロック**だけ**を BLOCK 形式で全文返す。ファイル全文は返さない。
- 変更していないブロックは返さない。

【ファイル全文】
{{FULL}}
```

## 再依頼: 省略サインが出たとき

```
先ほどの返答に省略（「...省略...」「変更なし」など）が含まれていました。
次のブロックを、1 行も省略せずに全文で返してください。説明は不要です。

対象: {{NAMES}}
```
