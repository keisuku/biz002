# AI 返答フォーマット仕様

管理ツール `codeblocks.html` の「④ 返答を取り込む」が解釈する形式です。
プロンプトにはこの仕様が自動で含まれるため、人が覚える必要はありません。
社内 AI が形式を守らなかった場合の**救済（フォールバック）**もここに書きます。

---

## 1. 主形式: ブロック丸ごと（封筒形式）

```
=== BLOCK: sumMinutes ===
// 日次の作業時間を合計する（分単位）
function sumMinutes(rows) {
  return rows.reduce((a, r) => a + r.minutes, 0);
}
=== END ===
```

- `=== BLOCK: 名前 ===` から `=== END ===` までが 1 ブロック。名前は既存ブロックの名前と一致させる。
- 中身は**そのトップレベル宣言の全文**。先頭のコメント行も含めて返す。
- 複数のブロックを返すときは、封筒を並べる。順序は問わない。
- 封筒の外に説明文を書いてよい（取り込み時に無視される）。
- 封筒の中を ``` で囲んでも囲まなくてもよい（取り込み時に外される）。

### 追加

```
=== NEW BLOCK: formatMinutes | after: sumMinutes ===
// 分を "H:MM" 形式にする
function formatMinutes(min) { ... }
=== END ===
```

- `after: 既存名` で挿入位置を指定する。省略時は「対象ブロックの直後」または末尾（起動行の前）に入る。
- HTML/CSS に追加する場合は `after: css#2` のように既存ブロック名を指定する。

### 削除

```
=== DELETE BLOCK: oldHelper ===
```

- 本文なし。取り込み時に赤い「削除」カードとして表示され、チェックした場合のみ適用される。

### HTML / CSS ブロック

- 名前は管理ツールの一覧に出ている名前をそのまま使う（例: `css#1`, `css: 一覧テーブル`, `html: 画面: 入力`）。
- 中身はその範囲の全文。`<style>` タグや `<script>` タグ自体は含めない。

## 2. 禁止事項（取り込み時に警告になる）

| 検出されるもの | 例 | 取り込み側の扱い |
|---|---|---|
| 省略サイン | `// ...省略...`, `/* 変更なし */`, `...existing code...`, `(以下同じ)`, 行全体が `...` | ⚠ 警告。「省略せず全文で」の再依頼プロンプトを出す |
| 名前の不一致 | `=== BLOCK: foo ===` の中身が `function bar` | ⚠ 警告（AI が改名した可能性） |
| 複数宣言 | 1 つの封筒に 2 つ以上のトップレベル宣言 | ⚠ 警告。適用は可能（ブロックが分割される） |
| 行数の急減 | 元の半分未満 かつ 10 行以上減 | ⚠ 警告（省略の疑い） |
| 構文エラー | 括弧の不一致など | ✖ 適用不可（そのブロックだけ） |

## 3. 救済（封筒がない場合）

AI が封筒を付けず、コードだけを返した場合:

1. 返答から ``` コードフェンスの中身を取り出す（フェンスがなければ全文）。
2. それを JS としてトップレベル分割する。
3. 名前が既存ブロックと一致 → 「置換」候補、一致しない → 「追加」候補（位置は末尾）。
4. 名前のない文（`stmt#`）は無視し、警告を出す。

## 4. 救済（全文 HTML が返ってきた場合）

`<!DOCTYPE` や `<html` で始まる返答は「ファイル全文」とみなし、
現在のファイルと**ブロック名で突き合わせて**差分（置換 / 追加 / 削除）を作る。
これにより従来の「全文を貼って全文をもらう」運用からも、ブロック単位の確認ができる。

## 5. 正規表現（実装の目安）

```
開始: ^\s*(?:```\w*\s*)?===\s*(BLOCK|NEW BLOCK|DELETE BLOCK)\s*:\s*(.+?)\s*===\s*$
終了: ^\s*===\s*END\s*===\s*(?:```)?\s*$
名前部: 名前 [ | after: 既存名 ]
```
