# CodeBlocks — オフライン単一 HTML のためのブロック単位コード管理ツール

`codeblocks.html` をブラウザ（Edge / Chrome）で開くだけで動きます。
ネットワーク・インストール・Node・Python は不要。**本体 HTML を書き換えずに**、
関数などの「ひとかたまり（ブロック）」に分けて、AI に差し替えを依頼し、返答を安全に取り込みます。

```
① 読み込む → ② 選ぶ → ③ AIに依頼 → ④ 返答を取り込む → ⑤ 保存
```

## 何ができるか

| 困りごと | このツールでどうなるか |
|---|---|
| 30 万文字を毎回 AI に全文貼っている | 直したい関数＋関連関数の**署名だけ**を渡すプロンプトを自動生成（全文モードも残してある） |
| AI が「...省略...」で返してくる | 取り込み時に**省略サインを検出**して警告、「省略せず全文で」の再依頼プロンプトをワンクリック生成 |
| 手作業で本体に貼っていて壊れる | ブロック名で突き合わせ、**行差分を見てチェックしたものだけ適用**。適用後に構文チェック、取り消しも可 |
| 本体にマーカーを入れたくない | 解析だけで境界を導出（トップレベル宣言単位）。**復元チェック**で元と完全一致することを毎回確認 |
| 部品を他ツールでも使いたい | 選んだ関数＋依存を 1 つの JS に抽出、全ブロックのカタログ (Markdown)、1 ブロック 1 ファイルの zip |

## 5 分で試す

1. `codeblocks.html` をブラウザで開く
2. 「サンプルで試す」を押す
3. ② で `sumMinutes` にチェック → ③ でプロンプトを見る → ④ で「サンプルの返答を貼る」→ 差分を見て「適用」→ ⑤ でダウンロード
4. ④ で「省略入りの返答例」を押すと、警告と再依頼ボタンの動きが確認できる

## ファイル構成

```
tools/codeblocks/
  codeblocks.html          管理ツール本体（これ 1 つを社内 PC に置く）
  README.md                このファイル
  docs/
    WORKFLOW.md            日々の作業手順（最初に読む）
    CONVENTIONS.md         AI と人が守る開発規約（プロンプトに自動挿入される要約を含む）
    RESPONSE_FORMAT.md     AI 返答フォーマット仕様（BLOCK / NEW BLOCK / DELETE BLOCK と救済ルール）
    PROMPTS.md             プロンプト雛形の原本（ツールの「設定」で編集できる内容と同じ）
  samples/
    sample_app.html        規約に沿った練習用の小さなツール（ツールにも内蔵）
    sample_response.txt    正しい形式の AI 返答例
    sample_response_bad.txt 省略サイン入りの返答例
  test/
    run_tests.mjs          開発用テスト（node で実行。社内 PC では不要）
```

## 社内 PC への配布

`codeblocks.html` 1 ファイルをコピーするだけです。docs/ は読み物なので一緒に置くと便利ですが、動作には不要です。
設定（テンプレートの編集）はブラウザの localStorage に保存されます。

## 仕組みの要点

- **ブロック** = トップレベル宣言（`function foo`, `const BAR`, `class Baz`）。名前のない文は `stmt#N`。
  CSS / HTML は `<style>` や見出しコメント（`/* ==== */`, `<!-- ==== -->`）で粗く分けます。
- 文字列・テンプレートリテラル・正規表現・コメントの中の括弧に惑わされない軽量スキャナで分割します。
  正規表現リテラルの判定はヒューリスティックなので、**復元チェック**（分割→結合が元と一致）を毎回行い、結果を表示します。
- 依存関係（呼んでいる / 呼ばれている）は識別子の突き合わせで求めます。多めに拾う方向に倒してあります。
- AI 返答は「封筒形式」が主。封筒が無いコードだけの返答、ファイル全文の返答も救済して取り込めます。
- 履歴機能はありません。ダウンロード名に日時が付くので、古いファイルを残す運用にしてください。

## 管理ツール自身の改修

`codeblocks.html` は自分の規約（1 つの `<script>`、トップレベル関数の並び、`// ==== セクション ====` 見出し、
状態は `const STATE` のみ）で書かれています。`codeblocks.html` を `codeblocks.html` 自身に読み込ませて、
同じ手順で改修できます。

## 開発者向け

```
node tools/codeblocks/test/run_tests.mjs
```

テストはツール本体から `<script>` を抜き出して Node の vm で評価し、分割の往復一致・応答パース・適用・差分などを検証します。
